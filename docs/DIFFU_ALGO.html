The algo.py Atlas

Every language-modelling algorithm in flm/algo.py, written out as math and drawn as diagrams. Each section gives the forward (noising) process, the training loss exactly as the code computes it, and the sampler, with the code variable that holds each symbol.

Notation and the map

Symbols are named after the code's variables. Clean tokens are \(x_0\) (x0, shape (B, L)) in the discrete sections, and \(x_1\) (x1) in the flow sections, where data sits at \(t=1\). Noisy inputs are \(x_t\) (xt / x_t). \(V\) is self.vocab_size (utils.py calls it K), \(e_v\) is the one-hot of token \(v\) (F.one_hot), \(\mathbf 1\) is the all-ones vector and \(m\) is mask_index. The network's per-position distribution over the clean token is \(x_\theta(x_t)\); the code holds its log, log_x_theta. Losses are per token, averaged over valid tokens by _loss.

Family 1 · Autoregressive

AR: next-token prediction

class AR(TrainerBase) algo.py:16

The baseline. The joint distribution factorises left to right:

\[ p_\theta(x) = \prod_{i=1}^{L-1} p_\theta\!\left(x^{i+1}\mid x^{1:i}\right), \qquad \ell_i = -\log p_\theta\!\left(x^{i+1}\mid x^{1:i}\right). \]

_process_model_input shifts the sequence (input = x[:, :-1], target = x[:, 1:]), and nll sets the [MASK] logit to \(-\infty\) before the log-softmax, so the extra mask token, which only exists so all algorithms share a vocabulary, can never be predicted.

Sampling

generate_samples pre-draws Gumbel noise \(g\in\mathbb R^{L\times V}\), \(g_{i,v}\sim\text{Gumbel}(0,1)\), and decodes one token per forward pass using the Gumbel-max trick, which is an exact sample from \(p_\theta\):

\[ x^{i+1} = \arg\max_v \left[\log p_\theta(v\mid x^{1:i}) + g_{i,v}\right] \;\sim\; p_\theta(\cdot\mid x^{1:i}). \]

This takes \(L-1\) sequential network calls (no KV cache here), which is the cost every other family tries to beat.

Family 2 · Masked (absorbing-state) diffusion · t = 0 clean, t = 1 all masks

Masked diffusion

All three classes share the forward process in AbsorbingState.q_xt: each token independently survives with probability \(\alpha_t\) and otherwise becomes [MASK].

\[ q(x_t^i \mid x_0^i) = \operatorname{Cat}\!\big(\alpha_t\, e_{x_0^i} + (1-\alpha_t)\, e_m\big),\qquad \alpha_t = 1-(1-\epsilon)t,\quad d\alpha_t = -(1-\epsilon),\quad \epsilon = 10^{-3}. \]

This is the LogLinear schedule; the name comes from \(\sigma_t = -\log\alpha_t = -\log(1-(1-\epsilon)t)\). The prior at \(t=1\) is (almost) all masks. Once a token is unmasked during sampling it never changes again.

MDLM

class MDLM(AbsorbingState) algo.py:70

Parameterisation (SUBS). _process_model_output enforces two facts that are true of the real posterior: the clean token is never [MASK], and a visible token is already correct.

\[ x_\theta(x_t)^i_m = 0, \qquad x_\theta(x_t)^i = e_{x_t^i}\ \text{ if } x_t^i \neq m \quad(\text{"carry-over"}). \]

Loss. With those constraints the continuous-time ELBO collapses to a weighted cross-entropy on the masked positions only (unmasked positions contribute \(\log 1 = 0\)):

\[ \mathcal L_{\text{MDLM}} = \mathbb E_{t\sim U[0,1]}\,\mathbb E_{x_t\sim q}\; \sum_{i}\; \frac{d\alpha_t}{1-\alpha_t}\, \log\big\langle x_\theta(x_t)^i,\, e_{x_0^i}\big\rangle . \]

Since \(d\alpha_t<0\) the weight \(d\alpha_t/(1-\alpha_t) \approx -1/t\) is negative, so each term is a positive cross-entropy, up-weighted at low noise. Code: log_p_theta * dalpha_t / (1 - alpha_t).

Sampler (ancestral_cache). For \(s<t\), a masked position is resampled from the reverse posterior, and visible tokens are copied:

\[ p_\theta(x_s^i \mid x_t) = \frac{\alpha_s-\alpha_t}{1-\alpha_t}\, x_\theta(x_t)^i + \frac{1-\alpha_s}{1-\alpha_t}\, e_m \quad\text{if } x_t^i=m, \qquad x_s^i = x_t^i \text{ otherwise}. \]

The code builds the unnormalised vector q_xs = p_x0 * (alpha_s - alpha_t), q_xs[mask] = 1 - alpha_s; sample_categorical uses the exponential-race form of Gumbel-max, so normalisation is unnecessary. The "cache" means the denoiser output is reused when a step unmasks nothing, so the network is called at most once per newly revealed token group.

Score view. _get_score also exposes the concrete score \(s(x_t)_y = p_t(y)/p_t(x_t)\) for the analytic sampler. For a masked position and an unmasked candidate \(y\):

\[ s_\theta(x_t)_y = x_\theta(x_t)_y\,\frac{\alpha_t}{1-\alpha_t} = \frac{x_\theta(x_t)_y}{e^{\sigma_t}-1},\qquad \log k = -\log\!\big(e^{\sigma_t}-1\big)\ (\texttt{log\_k}). \]

D3PMAbsorb

class D3PMAbsorb(AbsorbingState) algo.py:144

The same forward process in discrete time: \(T\) steps, \(t\in\{1/T,\dots,1\}\), \(s=t-\mathit{dt}\) with \(\mathit{dt} = 1/T\). The network uses the "mean" parameterisation: \(x_\theta\) is a full softmax that may put mass \(x_\theta(m)\) on the mask token. The loss is the discrete-time ELBO:

\[ \mathcal L_{\text{D3PM}} = \underbrace{-\log p_\theta(x_0\mid x_0)}_{\texttt{\_reconstruction\_loss}} \;+\; T\;\mathbb E_t \sum_{i:\,x_t^i=m} \mathrm{KL}\!\Big(q(x_s^i\mid x_t^i, x_0^i)\,\Big\|\,p_\theta(x_s^i\mid x_t)\Big). \]

For a masked position the true posterior is two-point: unmask to \(x_0^i\) with probability \(\mathit{dt}/t\), stay masked with probability \(1-\mathit{dt}/t\). The model posterior is \(p_\theta(x_s = v) \propto \mathit{dt}\,x_\theta(v)\) for \(v\neq m\) and \(\propto (1-\alpha_s)(1-x_\theta(m)) + x_\theta(m)\) for \(m\), with normaliser \(Z = t + \alpha_t x_\theta(m)\). Writing \(x_m = x_\theta(m)\), the KL in closed form is

\[ \mathrm{KL} = \frac{\mathit{dt}}{t}\Big[\log\!\Big(1+\tfrac{\alpha_t x_m}{t}\Big) - \log x_\theta(x_0^i)\Big] + \Big(1-\frac{\mathit{dt}}{t}\Big)\Big[\log\!\Big(1+\tfrac{\alpha_t x_m}{t}\Big) - \log\!\Big(1+\tfrac{\alpha_s x_m}{t-\mathit{dt}}\Big)\Big], \]

which is term_1_coef·(term_1_log_nr − term_1_log_dr) + term_2_coef·(term_2_log_nr − term_2_log_dr). In the derivation \(\alpha_s = 1-(t-\mathit{dt})\); the code sets alpha_s = t - dt (see issues).

SEDDAbsorb

class SEDDAbsorb(AbsorbingState) algo.py:190

SEDD learns the concrete score (ratios of marginals) instead of a clean-token distribution. The raw network output \(f_\theta\) is shifted so that, at initialisation, it already matches the scale of the true ratio, and the entry for the current token is pinned to \(\log 1 = 0\):

\[ \log s_\theta(x_t)_y = f_\theta(x_t)_y - \log\!\big(e^{\sigma_t}-1\big) - \log(V-1), \qquad \log s_\theta(x_t)_{x_t} = 0. \]

Loss: denoising score entropy. For a masked position with clean token \(x_0\), the only non-zero true ratio is \(q_{\text{ratio}} = 1/(e^{\sigma_t}-1)\) at \(y=x_0\) (q_ratio):

\[ \ell_i = d\sigma \Big[\; \underbrace{\sum_{y\neq m} s_\theta(x_t)_y}_{\texttt{pos\_term}} \;-\; \underbrace{q_{\text{ratio}} \log s_\theta(x_t)_{x_0}}_{\texttt{neg\_term}} \;+\; \underbrace{q_{\text{ratio}}(\log q_{\text{ratio}} - 1)}_{\texttt{const}} \;\Big],\qquad d\sigma = -\frac{d\alpha_t}{\alpha_t}\ (\texttt{dsigma}). \]

This is a Bregman divergence between \(s_\theta\) and the true ratio, so it is minimised (at zero) exactly when \(s_\theta(x_t)_{x_0} = q_{\text{ratio}}\) and the score on other tokens is zero in expectation. Unmasked positions contribute 0.

Sampler (analytic, Tweedie τ-leaping). For a step from \(\sigma_t\) to \(\sigma_s\), \(d\sigma = \sigma_t-\sigma_s\), a masked position moves to token \(y\) with weight \((e^{d\sigma}-1)\,s_\theta(x_t)_y\) and keeps the remaining mass on [MASK] (_staggered_score × _transp_transition). The final _denoiser_update zeroes the mask column so every position is filled.

Family 3 · Uniform-state diffusion · t = 0 clean, t = 1 uniform random

Uniform diffusion and DUO

UniformState.q_xt replaces a token by one drawn uniformly from the whole vocabulary (possibly itself):

\[ q(x_t\mid x_0) = \operatorname{Cat}\!\Big(\alpha_t\, e_{x_0} + \frac{1-\alpha_t}{V}\mathbf 1\Big). \]

Unlike masking, a token can change several times during sampling, so the model can fix its own mistakes. The price is that the posterior and ELBO are more involved.

DUO_BASE: posterior and ELBO

class DUO_BASE(UniformState) algo.py:276

Posterior (_compute_posterior). For \(s<t\), with alpha_ts \(\alpha_{ts}=\alpha_t/\alpha_s\) and d_alpha \(=\alpha_s-\alpha_t\), the exact posterior given a one-hot x (the clean \(e_{x_0}\) in training, \(x_\theta\) when sampling) is

\[ q(x_s\mid x_t, x) = \frac{V\alpha_t\, x\odot e_{x_t} + (\alpha_{ts}-\alpha_t)\,e_{x_t} + d_\alpha\,x + \frac{(1-\alpha_{ts})(1-\alpha_s)}{V}\mathbf 1}{V\alpha_t\, x_{x_t} + 1 - \alpha_t}. \]

The ancestral sampler (_ancestral_update) plugs in x = self.forward(x, sigma_t).exp(), i.e. \(x \leftarrow x_\theta(x_t)\), optionally applies nucleus filtering, and samples. The four numerator terms read: stay at \(x_t\) because it was clean; stay at \(x_t\) because noise happened to land there; jump to the predicted clean token; jump anywhere.

ELBO (nll_per_token, "Eq. 5"). Define the noised marginals of the truth and the prediction,

\[ \bar x = V\alpha_t\, e_{x_0} + (1-\alpha_t)\mathbf 1, \qquad \underbrace{\bar x^\theta = V\alpha_t\, x_\theta(x_t) + (1-\alpha_t)\mathbf 1}_{\texttt{x\_bar\_theta}} . \]

The per-token continuous-time NELBO is

\[ \ell = \underbrace{\frac{d\alpha_t}{V\alpha_t}}_{\texttt{coeff}}\left[\underbrace{\frac{V}{\bar x_{x_t}} - \frac{V}{\bar x^\theta_{x_t}}}_{\texttt{term1}} \;-\; \underbrace{\sum_{j=1}^{V} \frac{\bar x_j}{\bar x_{x_t}}\, \log\frac{\bar x^\theta_{x_t}\, \bar x_j}{\bar x^\theta_j\, \bar x_{x_t}}}_{\texttt{term2}}\right]. \]

Because \(\bar x\) has only two distinct values, the code evaluates the sum over \(j\) in closed form, splitting on whether the noisy token equals the clean one (x_eq_xt): with \(c = \frac{1-\alpha_t}{V\alpha_t+1-\alpha_t}\) (const), the case \(x_t = x_0\) gives \(-c\big(\sum_j\log\bar x^\theta_j - V\log\bar x^\theta_{x_t}\big) + (V-1)\,c\log c\), and the case \(x_t\neq x_0\) adds the \(\frac{V\alpha_t}{1-\alpha_t}\log(\bar x^\theta_{x_0}/\bar x^\theta_{x_t})\) term. Code names: \(\bar x_{x_t}\) = xbar_xt, \(\bar x^\theta_{x_t}\) = xbar_theta_xt, \(\bar x^\theta_{x_0}\) = xbar_theta_x. Only x_bar_theta.log().sum(-1) touches all \(V\) entries.

DUO: uniform diffusion is argmax of Gaussian diffusion

class DUO(DUO_BASE) algo.py:429

DUO's key fact: run ordinary Gaussian diffusion on the one-hot vector and take the argmax. The result is exactly a uniform-state diffusion sample.

\[ x_t = \tilde\alpha_t\, e_{x_0} + \tilde\sigma_t\,\epsilon,\quad \epsilon\sim\mathcal N(0,I_V),\quad \tilde\alpha_t = \sqrt{\operatorname{sigmoid}(-\gamma_t)},\ \tilde\sigma_t = \sqrt{\operatorname{sigmoid}(\gamma_t)},\quad \gamma_t = \gamma_{\min} + t(\gamma_{\max}-\gamma_{\min}). \]

(_q_xt_gaussian; inside it \(\tilde\alpha_t,\tilde\sigma_t\) are the local variables alpha_t, sigma_t, renamed here so they don't clash with the discrete \(\alpha_t\).)

By symmetry the hard token xt_usdm \(=\arg\max_k x_{t,k}\) equals \(x_0\) with some probability \(P\) and is otherwise uniform over the other \(V-1\) tokens, which is exactly the uniform-state \(q(x_t\mid x_0)\) with (_gamma_to_alphat)

\[ \alpha_t = \mathcal T(\gamma_t) = \frac{V\,P(\gamma_t) - 1}{V-1}, \qquad P(\gamma) = \Pr\big[\arg\max x_t = x_0\big] = \int \phi(z)\,\Phi\!\Big(z + \frac{\tilde\alpha}{\tilde\sigma}\Big)^{V-1} dz. \]

The integral is pre-tabulated (integral_cache, built by python -m flm.utils), and the custom autograd function Integral looks up both \(P\) and \(dP/d\gamma\) so gradients flow through \(\alpha_t\).

Training loss (DUO.nll). While global_step ≤ curriculum_end:

  1. \(t\sim U\), \(\gamma_t\) as above, \(\alpha_t = \mathcal T(\gamma_t)\), and \(d\alpha_t \approx (\gamma_{\max}-\gamma_{\min})\cdot 1000\,[\mathcal T(\gamma_t+10^{-3})-\mathcal T(\gamma_t)]\) by finite difference.
  2. Sample \(x_t\). The network input is \(x_t/\tau_g\) (xt * _compute_gumbel_tau_inverse()), where \(\log_{10}\tau_g\) moves linearly from gumbel_tau_log10_start to …_end (so the input is a sharpening softmax relaxation of the one-hot argmax).
  3. The loss is the DUO_BASE NELBO evaluated at the hard token xt_usdm \(=\arg\max x_t\).

After the curriculum (or at eval), it falls back to Diffusion.nll with discrete \(x_t\sim q(x_t\mid x_0)\) (q_xt). The prior term is \(\mathrm{KL}(q(x_1\mid x_0)\,\|\,\text{Unif})\) (_prior_loss, with \(\alpha_1\) = alpha_1):

\[ \mathcal L_{\text{prior}} = \Big(\alpha_1 + \tfrac{1-\alpha_1}{V}\Big)\log\big((V-1)\alpha_1+1\big) + \Big(1-\tfrac1V\Big)(1-\alpha_1)\log(1-\alpha_1). \]

Distillation (discrete consistency distillation)

class Distillation(DUO) algo.py:537

Goal: a few-step sampler. A frozen copy of the model (the teacher, refreshed every update_teacher_every steps from EMA or current weights) looks at a slightly cleaner version of the same noise realisation, and the student must match it from the noisier one. Using the same \(\varepsilon\) for both times is the point of the Gaussian view: it couples \(\hat x_s\) and \(\hat x_t\) deterministically.

\[ x_t = \tilde\alpha_t e_{x_0} + \tilde\sigma_t\epsilon,\quad x_s = \tilde\alpha_s e_{x_0} + \tilde\sigma_s\epsilon,\quad s = t-dt,\qquad \hat x_t = \arg\max x_t,\ \ \hat x_s = \arg\max x_s. \]

(_sample_trajectory; \(\hat x_t\), \(\hat x_s\) are xt_discrete, xs_discrete.)

\[ \ell_{\text{kl-fwd}} = \sum_v p^{T}_v\big(\log p^{T}_v - \log p^{S}_v\big),\qquad \ell_{\text{kl-bwd}} = \sum_v p^{S}_v\big(\log p^{S}_v - \log p^{T}_v\big), \]

with \(\log p^T\) = log_x_theta_teacher \(=\log x_{\theta^-}(\hat x_s, s)\) and \(\log p^S\) = log_x_theta_student \(=\log x_\theta(\hat x_t, t)\). The gap grows over training so the student learns ever-larger jumps: dt \(= 2^{n}/T\) (_compute_dt) with \(n = \lfloor\text{step}/\texttt{update\_teacher\_every}\rfloor\), or linearly between linear_growth_min and max.

Rectification

class Rectification(DUO) algo.py:670

A rectified-flow analogue for uniform diffusion. Instead of independent uniform noise, training uses a coupling \((x_0, x_T)\): \(x_T\) is a paired "noise" sequence supplied by the data loader (for example, the starting point the model itself used to generate \(x_0\)). Each position takes the clean token with probability \(\alpha_t\) and the paired token xT otherwise (\(r\) = random):

\[ x_t^i = \begin{cases} x_0^i & r^i \le \alpha_t \\ x_T^i & r^i > \alpha_t \end{cases},\qquad r^i\sim U[0,1]\ \ (\text{or } U[g,1] \text{ when } \texttt{given\_t}=g). \]

The loss is either the DUO_BASE NELBO or, with use_simple_loss, plain cross-entropy \(-\log x_\theta(x_t)_{x_0^i}\). With onestep_mode, random \(>\alpha_t\) always, so \(x_t = x_T\) and the model learns the direct map \(x_T\mapsto x_0\). When no pair is given (eval), \(x_T\) is a fresh uniform prior sample, which recovers ordinary uniform diffusion.

Family 4 · Flow matching on one-hots · t = 0 noise, t = 1 data

FLM: flow matching language model

class FLM(FLMBase) algo.py:1043

FLM treats each position as a point in \(\mathbb R^V\) and learns the straight-line flow from Gaussian noise to the one-hot vector (corrupt_continuous):

\[ x_t = (1-t)\,\epsilon + t\, e_{x_1},\qquad \epsilon\sim\mathcal N(0, I_{L\times V})\ (\texttt{noise}),\qquad e_{x_1} = \texttt{target\_data}. \]

Denoiser. The network predicts the clean one-hot, i.e. a point on the simplex. Logits are soft-capped at ±30 before the softmax (_process_model_output):

\[ f = \log D_\theta(x_t,\tau_t) = \operatorname{log\,softmax}\!\Big(30\tanh\frac{\text{logits}}{30}\Big),\qquad D_\theta(x_t,\tau_t) \approx \mathbb E[e_{x_1}\mid x_t]. \]

Loss. Since \(e_{x_1}\) is one-hot, the target is a class label and the natural loss is cross-entropy, which is minimised by the posterior mean:

\[ \ell = -\sum_{k} \texttt{target\_data}_k\; f_k = -\log D_\theta(x_t,\tau_t)_{x_1}. \]

Velocity. Because \(\epsilon = (x_t - t e_{x_1})/(1-t)\), the flow-matching velocity \(\mathbb E[e_{x_1} - \epsilon\mid x_t]\) follows from the denoiser with no extra network:

\[ v = \frac{D_\theta(x_t,\tau_t) - x_t}{1-t}\qquad(\texttt{v = (x\_1\_pred\_probs - z) / (1 - t\_in)}). \]

Learnable loss weighting. With learnable_loss_weighting, a small network \(w(\tau_t)\) (loss_weight) rebalances noise levels via the uncertainty trick \(\tilde\ell = e^{-w(\tau_t)}\ell + w(\tau_t)\) (the optimum is \(w = \log\mathbb E[\ell\mid\tau_t]\), so all \(\tau\) contribute roughly equally).

Time reparameterisation: τ is "how much has argmax decoded"

The network is not conditioned on \(t\). It is conditioned on \(\tau_t\) (tau_t): training samples \(\tau_t\sim U[\texttt{t\_min},\texttt{t\_max}]\), then maps to \(t\) with a spline lookup table (_tau_to_t = utils.alpha_to_gamma). \(\tau\) is the DUO signal level of \(\arg\max x_t\):

\[ \tau_t = \frac{V}{V-1}\Big(\Pr[\arg\max x_t = x_1] - \frac1V\Big),\qquad \Pr[\arg\max x_t = x_1] = \mathbb E_{z\sim\mathcal N(0,1)}\Big[\Phi\Big(z + \frac{t}{1-t}\Big)^{V-1}\Big], \]

computed with Gauss–Hermite quadrature (compute_alpha_exact). So \(\tau\) is exactly the fraction of positions whose argmax is already correct, after removing chance. For a real vocabulary almost nothing happens for most of \(t\); then all tokens "snap" into place over a narrow window. Sampling \(\tau\) uniformly concentrates training where tokens are actually being decided.

Sampling (Euler, uniform in τ)

z ~ N(0, I) # t = 0 for τ_i in linspace(0, 1, N+1)[:-1]: t_i, t_{i+1} = t(τ_i), t(τ_{i+1}) D = D_θ(z, τ_i) if last step: z = D ; break # jump straight to the prediction z = z + (t_{i+1} − t_i) · (D − z) / (1 − t_i) return argmax_k z
Family 4 · Flow maps · t = 0 noise, t = 1 data

FMLM: flow map language model

class FMLM(FLMBase) algo.py:1103

FLM needs many Euler steps because each step follows the local velocity. A flow map \(X_{st}\) instead jumps directly from \(x_s\) to where the ODE trajectory would be at time \(t\). FMLM parameterises it through a two-time denoiser \(D_{st}(x)\) (the backbone gets both \(\tau_s\) and \(\tau_t\) through double_temb):

\[ X_{st}(x_s) = \frac{1-t}{1-s}\,x_s + \frac{t-s}{1-s}\,D_{st}(x_s),\qquad D_{st}(x_s) = \exp\big(\texttt{forward(x\_s, tau\_s, tau\_t)}\big). \]

This form has three useful properties. At \(t=s\) it is the identity, and \(D_{ss}(x)\) is just the FLM denoiser. At \(t=1\) it returns \(D_{s1}(x_s)\), a one-step generator. And for small \(t-s\) it is one Euler step, since \(X_{st}\approx x_s + (t-s)v_s\).

Which \((s,t)\) pairs are trained

Each batch is split by _get_split_indices (deterministically across GPUs) into three groups:

  • Diagonal (diagonal_fraction): \(s=t\). Target is the frozen FLM teacher's soft prediction \(D^{T}(x_s,\tau_s)\), or the one-hot \(e_{x_1}\) with no teacher. Loss is cross-entropy.
  • Boundary (share \((1-f)/\texttt{boundary\_prob}\)): \(s=0, t=1\), the one-step map itself.
  • Off-diagonal (the rest): \(s<t\), drawn either as two sorted uniforms (uniform_st) or as \(d\sim U,\ s\sim U\cdot(1-d),\ t=s+d\) (uniform_diff). Target comes from one of three self-distillation rules below.

All times are drawn in \(\tau\) and mapped to \(t\). The student is initialised from the teacher, with the last layer of the second time embedding zeroed, so at step 0 \(D_{st}(x) = D^T(x,s)\).

The three distillation methods differ only in how they build the off-diagonal target. Each one is a different identity that the exact flow map satisfies, rewritten in terms of \(D\).

PSD: progressive / semigroup distillation

Identity: two jumps equal one jump, \(X_{st} = X_{ut}\circ X_{su}\) for any \(s<u<t\). Take \(u\) at the \(\tau\)-midpoint (or random, set_midpoint). Substituting the parameterisation on both sides and solving for \(D_{s,t}\):

\[ \underbrace{D^\star_{st}}_{\texttt{offdiag\_target}} = \lambda_{sut}\, D_{su}(x_s) + (1-\lambda_{sut})\, D_{ut}\big(X_{su}(x_s)\big),\qquad \lambda_{sut} = \frac{(1-t)(u-s)}{(1-u)(t-s)}. \]

(The weights sum to one because \((1-t)(u-s) + (t-u)(1-s) = (1-u)(t-s)\), so the target stays on the simplex.) Both hops use the current model under no_grad (or its EMA with use_ema_for_psd_target). Loss is cross-entropy \(-\sum_k \operatorname{sg}(D^\star)_k\log D_{st}(x_s)_k\) or, with use_mse_loss_psd, squared error, optionally scaled by \(\big(\tfrac{t-s}{1-s}\big)^2\) (the factor that converts a \(D\)-error into an \(X\)-error).

ESD: Eulerian self-distillation

Identity: the destination does not change if you slide the start point along the trajectory. With \(x_s\) moving at velocity \(v_s\):

\[ \frac{d}{ds}X_{st}(x_s) = \partial_s X_{st} + \big(\nabla_x X_{st}\big)\,v_s(x_s) = 0. \]

Plugging in the parameterisation and \(v_s = (D_s - x_s)/(1-s)\), where \(D_s\) is the teacher's instantaneous denoiser, the \(x_s\) terms cancel and we get a fixed-point equation for \(D\):

\[ D^\star_{st} = D_s + \underbrace{\frac{(1-s)(t-s)}{1-t}}_{\texttt{coeff}}\;\underbrace{\frac{d}{ds}D_{st}(x_s)}_{\texttt{d\_ds\_D\_st}}. \]

The total derivative is one forward-mode JVP (torch.func.jvp, with the custom jvp_attn kernel) of \((\tau_s, x_s)\mapsto \log D_\theta\) along the tangent \(\big(\tfrac{d\tau_s}{ds},\ \tfrac{D_s - x_s}{1-s}\big)\), then \(\tfrac{d}{ds}D = D\odot\tfrac{d}{ds}\log D\). Loss is \(\big\|D_{st}(x_s) - \operatorname{sg}(D^\star)\big\|^2\) summed over the vocabulary.

LSD: Lagrangian self-distillation

Identity: the endpoint moves with the flow. Differentiating in the end time:

\[ \partial_t X_{st}(x_s) = v_t\big(X_{st}(x_s)\big) = \frac{D_t(X_{st}) - X_{st}}{1-t}. \]

Solving for \(D\) in the same way:

\[ D^\star_{st} = \underbrace{D_t\big(X_{st}(x_s)\big)}_{\texttt{D\_t\_\_X\_st}} - \frac{(t-s)(1-t)}{1-s}\;\underbrace{\partial_t D_{st}(x_s)}_{\texttt{partial\_t\_D\_st}}. \]

Here the JVP is with respect to \(\tau_t\) only (tangent 1), multiplied by \(d\tau/dt\) via the chain rule. \(D_t\) is the teacher (use_teacher_for_D_t_lsd) or the student's own diagonal. Because subtracting a derivative can push \(D^\star\) off the simplex, the target is projected back with α-entmax (entmax_temp_lsd ∈ [1, 2]; 1 = softmax, 2 = sparsemax), and the loss is cross-entropy.

Sampling with a flow map (optional stochasticity γ)

With \(\gamma = 0\) the sampler just chains flow-map jumps on a \(\tau\)-uniform grid, \(z \leftarrow X_{t_i,t_{i+1}}(z)\), and returns \(D\) on the last step. With \(\gamma>0\) it jumps past the target noise level and re-injects fresh noise. Writing \(\sigma = 1-t\) for the noise coefficient and \(\sigma_{\text{target}} = 1-t_{i+1}\):

\[ \tilde\sigma = \sigma_{\text{target}}\sqrt{1-\gamma^2},\quad \tilde t = 1-\tilde\sigma,\qquad \tilde z = X_{t_i,\tilde t}(z),\qquad z \leftarrow \tilde z + (\tilde\sigma - \sigma_{\text{target}})\,D + \gamma\,\sigma_{\text{target}}\,\xi,\ \ \xi\sim\mathcal N(0,I). \]

If \(\tilde z \approx \tilde t\, e_x + \tilde\sigma\,\varepsilon\) and \(D\approx e_x\), the new state has data weight \(\tilde t + \tilde\sigma - \sigma_{\text{target}} = t_{i+1}\) and noise std \(\sqrt{\tilde\sigma^2 + \gamma^2\sigma_{\text{target}}^2} = \sigma_{\text{target}}\), i.e. exactly the marginal at \(t_{i+1}\). \(\gamma\) trades determinism for error correction.

Two-model and two-stage flow maps

FMLM_TwoModel: velocity plus learned curvature

class FMLM_TwoModel(FLMBase) algo.py:1639

Here the flow map is a second-order Taylor step. The velocity comes from the frozen FLM teacher, and a second network \(g_\theta\) (raw output, no softmax, last layer zero-initialised so it starts at 0) learns the correction:

\[ X_{st}(x_s) = x_s + dt\,\hat v_s + \tfrac12 dt^2\, g_\theta(x_s,s,t),\qquad dt = t-s,\quad \hat v_s = \frac{f^\theta_s - x_s}{1-s},\quad f^\theta_s = D^T(x_s,\tau_s). \]

Bootstrap target. Split \([s,t]\) at the \(\tau\)-midpoint \(u\) (t_mid), with \(dt_1 = u-s\) (dt_half_1) and \(dt_2 = t-u\) (dt_half_2). Take two half-steps with the current model (no grad), average their velocities, and extrapolate to \(t=1\). Code names: \(\hat v_{su}\) = v_s_u_hat, \(F_{su}\) = large_f_s_u, \(\hat v_{ut}\) = v_u_t_hat, \(\hat v\) = v_hat.

\[ \begin{aligned} \hat v_{su} &= \hat v_s + \tfrac12 dt_1\, g_\theta(x_s,s,u), & F_{su} &= x_s + dt_1\,\hat v_s + \tfrac12 dt_1^2\, g_\theta(x_s,s,u),\\ \hat v_{ut} &= \hat v_u(F_{su}) + \tfrac12 dt_2\, g_\theta(F_{su},u,t), & \hat v &= \frac{dt_1\,\hat v_{su} + dt_2\,\hat v_{ut}}{dt},\\ x_{\text{boot}} &= \operatorname{sg}\big(x_s + (1-s)\,\hat v\big). && \end{aligned} \]

The student's own average velocity \(\hat v_s + \tfrac12 dt\, g_\theta(x_s,s,t)\), extrapolated the same way, is \(f^\theta_s + \tfrac12 dt(1-s)\,g_\theta(x_s,s,t)\) (f_final = f_final_fm + weight * f_final_sc). The loss is the squared error in endpoint space, summed over the vocabulary:

\[ \ell = \big\|\underbrace{x_{\text{boot}} - f^\theta_s - \tfrac12 dt(1-s)\,g_\theta(x_s,s,t)}_{\texttt{error}}\big\|^2 = V\cdot\operatorname{mean}_k\,\texttt{error}_k^2 . \]

With add_boundary, a fraction \(1/\texttt{boundary\_prob}\) of the batch uses \(\tau_s=0\), d_tau \(=1\). Sampling is the Taylor step \(z\leftarrow z + dt\, v(z) + \tfrac12 dt^2 g_\theta(z,s,t)\), which costs two network calls per step (teacher + \(g\)).

FMLM_TwoStage: compress the two models into one

class FMLM_TwoStage(FLMBase) algo.py:1798

Stage two removes the extra network. Two frozen teachers, FLM (teacher_model_f, giving \(v_f\)) and a trained TwoModel (teacher_model_g, giving f_final_g), define the target jump, and a single FMLM-style student with the \(D\)-parameterisation must reproduce it:

\[ F_{st} = x_s + dt\, v_f + \tfrac12 dt^2\, \texttt{f\_final\_g}, \qquad F^{\text{distilled}}_{st} = x_s + dt\,\underbrace{\frac{D_{st}(x_s) - x_s}{1-s}}_{\texttt{student\_v}}, \qquad \ell = \big\|F_{st} - F^{\text{distilled}}_{st}\big\|^2 . \]

After training, sampling is identical to FMLM (one network call per step, same optional \(\gamma\) noise).

Issues found in the code

Writing out the math exposed a few places where the code and the derivation disagree. None are fixed here; they are listed so you can check them.

Likely bug · algo.py:168 D3PMAbsorb uses the wrong \(\alpha_s\). alpha_s = t - dt, but for the log-linear schedule \(\alpha_s = 1-s = 1-(t-dt)\). The derivation above needs \(\log(1 + \alpha_s x_m/(t-dt))\). As written, term_2_log_dr reduces to \(\log(1+x_m)\). This only matters when the model puts mass on [MASK] (subs_masking=False).
Crash · algo.py:1179 utils.d_alpha_by_d_gamma does not exist. FMLM._d_tau_by_d_t calls it, and both ESD and LSD use that method for the chain-rule factor \(d\tau/dt\). Any FMLM run with distillation_method ESD or LSD should raise AttributeError on the first off-diagonal batch. PSD is unaffected. The spline already supports it: lut_g2a.derivative()(t).
Inconsistent conditioning · algo.py:1414, 1436 ESD passes raw \(t\) where the network expects \(\tau\). The ESD diagonal branch calls self.forward(x_s[idx_diag], s[idx_diag], t[idx_diag]), whereas PSD and LSD pass tau_s, tau_t. Also, when no teacher is used, ESD's "instantaneous" \(D_s\) is computed as forward(x_s, tau_s, tau_t), which is the two-time \(D_{s,t}\), not \(D_{s,s}\).
Silent failure · algo.py:558, 654 Distillation accepts loss types it doesn't implement. Validation allows "posterior" and "kl-posterior", but nll only handles kl-fwd and kl-bwd and returns None otherwise.
No-op · algo.py:829 In FLMBase._loss, the ignore_bos branch assigns loss[:, 1:] = loss[:, 1:], which changes nothing, so the BOS token is still counted.
